# ImageKit image provenance

The pear photograph and transparent layered-image loading poster were generated for this project with the built-in `image_gen.imagegen` tool on 2026-10-03. They depict a fictional studio still life.

- `pear-study.jpg` is a JPEG derivative of the generated `assets/plates/pear-study.png`, quality 92 with mozjpeg. Its exact prompt is embedded and repeated in the adjacent JSON.
- `layers-poster.webp` is a WebP derivative of `assets/plates/layers-poster.png`, quality 88 and alpha quality 95. Its exact prompt is in the adjacent JSON. The poster was freshly generated from the approved visual reference; it is not a cropped screenshot of the interface.

Shipping assets live in the repository root. The PNG originals are retained in the local design workspace. The live 3D view is actual Three.js geometry textured from the opened image, current crop and encoded output. The generated poster is used during initial loading. Controls and text are semantic HTML.

The approved design comp and development workflow files stay local and are not part of the published site.
